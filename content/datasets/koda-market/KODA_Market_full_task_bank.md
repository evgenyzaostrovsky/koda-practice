# KODA Market — полный банк задач

Общий источник данных: `koda_market_orders.csv`. Основной датафрейм уроков: `orders`.

Основное правило: в тексте задачи говорить человеческим языком. Названия колонок и код показывать в подсказках и техническом описании проверки, а не засорять условие.

## 1. Загрузка и обзор данных

1. **Первая загрузка.** Загрузи данные продаж и сохрани их в `orders`. Проверь, что даты распознаны как даты.
2. **Размер магазина.** Узнай, сколько строк и колонок в таблице.
3. **Первые заказы.** Покажи первые пять строк и определи, какие поля доступны.
4. **Типы данных.** Найди колонки, которые нужно привести к числовому или временному типу.
5. **Быстрый аудит.** Проверь пропуски и составь короткий список проблем в данных.

## 2. Выбор данных

1. Оставь в отдельной таблице только дату, город, категорию и выручку.
2. Покажи заказы, которые принесли больше 20 000 рублей.
3. Оставь только заказы из Москвы и Тулы.
4. Покажи первые заказы, оформленные через приложение.
5. Выбери строки с оценкой 5 и выручкой больше 10 000 рублей.

## 3. Сортировка

1. Найди десять самых дорогих заказов.
2. Отсортируй заказы по сроку доставки от самого долгого к самому короткому.
3. Покажи самые дешёвые заказы внутри каждого города.
4. Отсортируй клиентов по выручке, не меняя исходную таблицу.
5. Выведи заказы сначала по городу, а внутри города — по выручке.

## 4. Новые колонки

1. Рассчитай выручку до скидки.
2. Создай признак крупного заказа: выручка от 15 000 рублей.
3. Раздели заказы на маленькие, средние и крупные.
4. Рассчитай стоимость одной единицы товара.
5. Создай признак долгой доставки: больше трёх дней.

## 5. Фильтрация и даты

1. Оставь заказы только за январь.
2. Найди заказы, оформленные после 10 февраля.
3. Покажи заказы, доставленные не дольше двух дней.
4. Оставь оплаченные заказы с оценкой не ниже 4.
5. Найди заказы новых клиентов за последнюю неделю данных.

## 6. GroupBy и агрегации

Полный эталон этого раздела находится в `KODA_Market_groupby_lesson.md`.

1. Общая выручка по городам.
2. Средний чек по каналам.
3. Три показателя по менеджерам.
4. Продажи по городам и категориям.
5. Доля отменённых заказов по каналам.
6. Клиенты с повторными заказами.
7. Лучшая категория каждого города.
8. Средняя оценка по категориям.
9. Средний срок доставки по городам.
10. Итоговый отчёт для директора.

## 7. `transform`

1. Добавь к каждому заказу общую выручку его города.
2. Рассчитай долю заказа в выручке города.
3. Посчитай отклонение заказа от среднего чека его канала.
4. Добавь к каждой строке средний срок доставки в её городе.
5. Оставь заказы, которые выше среднего по своей категории.

## 8. Пропуски и качество

1. Найди колонки с пропусками и посчитай их количество.
2. Покажи заказы без оценки клиента.
3. Замени пропущенные оценки специальным значением и объясни, почему это допустимо или недопустимо.
4. Сравни долю пропусков по каналам.
5. Проверь, есть ли пропуски в ключевых полях заказа.

## 9. Дубликаты

1. Проверь, встречается ли номер заказа больше одного раза.
2. Найди клиентов, у которых дублируются строки.
3. Удали полные дубликаты, сохранив исходную таблицу.
4. Найди повторяющиеся сочетания клиента и заказа.
5. Посчитай, сколько выручки может быть задвоено.

## 10. Pivot и reshape

1. Построй таблицу выручки по городам и категориям.
2. Сравни каналы в строках, а месяцы — в колонках.
3. Получи количество заказов по статусам и городам.
4. Преврати широкую таблицу показателей в длинную.
5. Собери мини-отчёт с выручкой и количеством заказов в одной сводной таблице.

## 11. Объединение таблиц

Используй связанные таблицы `customers`, `products` и `managers`.

1. Подтяни к заказам сегмент клиента.
2. Добавь к продажам бренд товара.
3. Проверь, какие заказы не нашли клиента.
4. Сравни внутреннее и левое объединение на данных магазина.
5. Объедини заказы с данными менеджеров и посчитай выручку по стажу.

## 12. Даты и временные ряды

1. Посчитай выручку по месяцам.
2. Сравни будние и выходные дни.
3. Найди день с максимальной выручкой.
4. Рассчитай накопительную выручку за период.
5. Сравни текущую неделю с предыдущей.

## 13. Строки и категории

1. Приведи названия категорий к единому виду.
2. Найди товары, в названии которых есть слово «монитор».
3. Создай короткий код канала продаж.
4. Проверь, нет ли лишних пробелов в названиях.
5. Составь отчёт по первой букве товара.

## 14. `map`, `apply`, `lambda`

1. Переведи статусы на короткие английские коды.
2. Рассчитай уровень клиента по количеству заказов.
3. Создай текстовый комментарий по оценке доставки.
4. Раздели товары на ценовые сегменты.
5. Сравни решение через `map` и через `apply`.

## 15. Визуализация

1. Построй столбчатый график выручки по городам.
2. Покажи динамику выручки по датам.
3. Сравни каналы продаж на одном графике.
4. Покажи распределение сроков доставки.
5. Построй график средней оценки по категориям и сделай один деловой вывод.

## 16. Итоговые pandas-кейсы

1. Почему выручка одного города упала: проведи декомпозицию по каналам и категориям.
2. Найди канал с большим количеством отмен и проверь, не связан ли он с доставкой.
3. Составь профиль лучшего клиента.
4. Подготовь таблицу для еженедельного отчёта руководителя.
5. Напиши пять выводов по магазину, каждый подкрепи расчётом.

## 17. SQL на тех же данных

1. Покажи оплаченные заказы дороже 10 000 рублей.
2. Посчитай выручку по городам через `GROUP BY`.
3. Сравни каналы через агрегаты.
4. Найди повторных клиентов.
5. Рассчитай долю отменённых заказов.
6. Получи топ-3 заказа каждого города оконной функцией.
7. Сравни текущий месяц с предыдущим.
8. Собери отчёт через CTE.
9. Подтяни данные клиента через `JOIN`.
10. Проверь размножение строк после объединения.

## 18. Excel

1. Импортируй CSV и преврати его в таблицу.
2. Построй сводную по городам и категориям.
3. Рассчитай выручку формулой и сравни с готовым полем.
4. Добавь условное форматирование отменённых заказов.
5. Собери лист руководителя с KPI.
6. Сделай фильтр по каналу и городу.
7. Рассчитай средний чек формулами.
8. Найди ошибки и пропуски.
9. Построй график динамики.
10. Подготовь короткий вывод для письма руководителю.

## 19. Power BI

1. Загрузи датасет и проверь типы колонок.
2. Создай карточки выручки и количества заказов.
3. Построй разрез выручки по городам.
4. Добавь фильтр по каналу.
5. Создай показатель среднего чека.
6. Покажи динамику по месяцам.
7. Настрой страницу качества доставки.
8. Добавь взаимодействие графиков.
9. Проверь, что отменённые заказы выделяются отдельно.
10. Сформулируй три вывода по дашборду.

## Правило наполнения

Каждый пункт выше нужно превратить в полноценную задачу по стандарту урока `groupby`: ситуация, человеческое условие, датафрейм, ожидаемый результат, три подсказки, разбор и автоматическая проверка. Не оставляй пункты в виде заглушек при интеграции в приложение.
