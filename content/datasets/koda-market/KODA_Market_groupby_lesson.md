# KODA Market — урок `groupby`

## Контекст

Ты работаешь младшим аналитиком в интернет-магазине KODA Market. Заказы компании находятся в датафрейме `orders`, загруженном из файла `koda_market_orders.csv`.

```python
import pandas as pd

orders = pd.read_csv('koda_market_orders.csv', parse_dates=['order_date'])
```

В каждой задаче используется тот же самый датафрейм `orders`. Представь, что разные отделы присылают тебе запросы по этим заказам.

## Колонки датафрейма

| Колонка | Смысл |
|---|---|
| `order_id` | номер заказа |
| `order_date` | дата заказа |
| `customer_id` | клиент |
| `city` | город клиента |
| `channel` | канал заказа |
| `category` | категория товара |
| `product` | товар |
| `manager` | менеджер |
| `quantity` | количество товара |
| `price` | цена одной единицы |
| `discount` | скидка |
| `revenue` | выручка после скидки |
| `status` | статус заказа |
| `delivery_days` | срок доставки |
| `rating` | оценка клиента |
| `is_new_customer` | новый клиент или нет |

Во всех задачах ответ нужно сохранить в переменную `result`. Если в условии не сказано обратное, не изменяй исходный `orders`.

## Задачи одного рабочего дня

### 1. Выручка по городам

Руководитель продаж хочет понять, какой город приносит больше денег.

**Задание.** Сгруппируйте заказы по городу и посчитайте общую выручку для каждого города. Сохраните ответ в переменную result.

**Подсказки:**

1. В итоговой таблице каждый город должен встретиться один раз, а его продажи — сложиться.
2. Сгруппируйте датафрейм по городу и сложите продажи.
3. Заполните пропуски: `result = orders.groupby(_____)[_____].sum()`.

**После решения.** Какой город лидирует по выручке?

### 2. Средний чек по каналам

Маркетолог сравнивает заказы из приложения, сайта и магазина.

**Задание.** Посчитайте среднюю выручку одного заказа для каждого канала. Сохраните ответ в переменную result и округлите значения до двух знаков.

**Подсказки:**

1. В результате каждый канал должен встретиться один раз и получить свой средний чек.
2. Сгруппируйте `orders` по каналу и посчитайте среднее значение `revenue`.
3. Используйте `mean()` и округление через `.round(2)`.

**После решения.** Какой канал даёт самый высокий средний чек?

### 3. Заказы менеджеров

Руководителю отдела продаж нужны три показателя по каждому менеджеру.

**Задание.** Создайте таблицу с одной строкой на менеджера и тремя показателями:

- количеством заказов;
- общей выручкой;
- средней выручкой заказа.

Используйте `.agg()` и сохраните результат в `result`.

**Подсказки:**

1. Сгруппируйте `orders` по менеджеру и посчитайте три показателя.
2. Количество считайте по `order_id`, сумму и среднее — по `revenue`.
3. Используйте именованные агрегации: `orders_count=('order_id', 'count')` и так далее.

**После решения.** У кого самая высокая общая выручка, а у кого — средний чек?

### 4. Продажи по городам и категориям

Категорийный менеджер хочет понять, какие товары приносят деньги в каждом городе.

**Задание.** Посчитайте выручку для каждой пары «город — категория». Сохраните ответ в переменную result.

**Подсказки:**

1. В результате должна быть отдельная сумма для каждой пары «город — категория».
2. Сгруппируйте `orders` сразу по городу и категории и сложите `revenue`.
3. Передайте в `groupby()` список: `['city', 'category']`.

**После решения.** Какая категория сильнее всего в каждом городе?

### 5. Только оплаченные заказы

Финансовый отдел просит не учитывать отмены и возвраты в отчёте по городам.

**Задание.** Оставьте только оплаченные заказы, затем посчитайте общую выручку по городам.

**Подсказки:**

1. Сначала уберите строки со статусами `Возврат` и `Отменён`.
2. Отфильтруйте `status == 'Оплачен'`, сгруппируйте результат по городу и сложите `revenue`.
3. Выполните цепочку: `orders[orders['status'] == 'Оплачен'].groupby('city')['revenue'].sum()`.

### 6. Доля отменённых заказов

Операционный директор хочет сравнить качество каналов продаж.

**Задание.** Рассчитайте долю отменённых заказов для каждого канала в процентах. Сохраните ответ в переменную result и округлите значения до одного знака.

**Подсказки:**

1. Для каждого канала нужно разделить количество отменённых заказов на общее количество заказов.
2. Создайте булеву колонку: `status == 'Отменён'`. Её среднее значение — это доля отмен.
3. Сгруппируйте булеву Series по `channel`, примените `mean()`, умножьте на 100 и округлите.

### 7. Клиенты с повторными заказами

Команда лояльности ищет клиентов, которые покупали больше одного раза.

**Задание.** Посчитайте количество уникальных заказов каждого клиента и оставьте клиентов с двумя и более заказами.

**Подсказки:**

1. Один клиент может встречаться в нескольких строках. В результате нужны клиенты с повторными заказами.
2. Сгруппируйте `orders` по `customer_id` и посчитайте уникальные `order_id`.
3. Используйте `.nunique()`, затем отфильтруйте значения `>= 2` и отсортируйте их по убыванию.

### 8. Лучшая категория каждого города

Руководитель регионов хочет назначить каждому городу его самую прибыльную категорию.

**Задание.** Создайте таблицу с городом, категорией и выручкой. Для каждого города оставьте только категорию с максимальной выручкой.

**Подсказки:**

1. Сначала посчитайте выручку каждой пары «город — категория».
2. Затем найдите строку с максимальной выручкой внутри каждого города.
3. Для индексов победителей используйте `.groupby('city')['revenue'].idxmax()`.

### 9. Средняя оценка по категориям

Команда качества хочет понять, какие категории нравятся клиентам.

**Задание.** Посчитайте среднюю оценку по каждой категории. Пропуски не учитывайте. Сохраните ответ в переменную result.

**Подсказки:**

1. Для каждой категории нужна одна средняя оценка.
2. Сгруппируйте `orders` по `category` и найдите среднее `rating`.
3. Используйте `.mean()` и `.round(2)`.

### 10. Средний срок доставки по городам

Логистика хочет сравнить скорость доставки в разных городах.

**Задание.** Рассчитайте средний срок доставки для каждого города среди оплаченных заказов.

**Подсказки:**

1. В отчёт должны попасть только оплаченные заказы.
2. Отфильтруйте `status == 'Оплачен'`, сгруппируйте по `city` и найдите среднее `delivery_days`.
3. В конце округлите результат до одного знака.

### 11. Доля новых клиентов по каналам

Маркетолог хочет понять, какой канал лучше привлекает новых клиентов.

**Задание.** Рассчитайте долю новых клиентов по каждому каналу в процентах.

**Подсказки:**

1. Для каждого канала нужна доля строк, где `is_new_customer` равен `True`.
2. Среднее булевой колонки даёт нужную долю.
3. Сгруппируйте `is_new_customer` по `channel`, примените `mean()`, умножьте на 100 и округлите.

### 12. Итоговый отчёт для директора

Директор хочет одну таблицу для сравнения городов.

**Задание.** Создайте итоговую таблицу с одной строкой на город и четырьмя показателями:

- количеством заказов;
- общей выручкой;
- средней выручкой заказа;
- средним сроком доставки.

Сохраните результат в `result` и отсортируйте города по `total_revenue` от большего к меньшему.

**Подсказки:**

1. Все четыре показателя должны быть рассчитаны на уровне города.
2. Сгруппируйте `orders` по `city` и примените `.agg()` к нужным колонкам.
3. После агрегации переименуйте колонки, округлите средние и отсортируйте по `total_revenue`.

## Что закрепляет урок

- группировку по одной и нескольким колонкам;
- `sum`, `mean`, `count`, `nunique`;
- именованные агрегации через `.agg()`;
- фильтрацию до группировки;
- доли через среднее булевых значений;
- выбор строки с максимумом через `idxmax`;
- сортировку агрегированного результата.
