# Публикация KODA Practice на Render

Проект разворачивается одним Docker Web Service: FastAPI обслуживает полноценный Python runner, API и собранный React frontend. Прогресс хранится в SQLite на постоянном диске `/data`.

## Через Blueprint

1. Распакуйте архив и загрузите его содержимое в корень GitHub-репозитория.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml`; подтвердите создание сервиса `koda-practice`.
4. После статуса **Live** откройте выданный Render URL.

Проверка состояния доступна по `/api/health`, документация API — по `/docs`.

## Важно

Постоянный диск Render нужен для сохранения общего прогресса SQLite между перезапусками. Если план Render не поддерживает диск, удалите блок `disk` из `render.yaml` и задайте `KODA_DB_PATH=/tmp/koda.db`; в таком режиме прогресс может сбрасываться при новом деплое.
